## 👋 关于我

你好，我是 **uhhgxg**，一名计算机科学与技术专业本科生（2028 届），目前专注于 **AI Agent 应用开发**。

我关注 Agent 工具调用、记忆与上下文管理、RAG，以及用可复现的评测验证系统表现。我喜欢把想法落成可以运行和演示的应用，也持续通过开源协作练习工程开发。
